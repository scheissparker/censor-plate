# German plate regression photograph

`german-car.jpg` is a resized, re-encoded primary frame of:
https://commons.wikimedia.org/wiki/File:Unmarked_police_car_from_Berlin_(2026_05).jpg

Author: Kaap bij Sneeuw. Date: 7 May 2026.
The source page dedicates the photograph under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

The original is a two-frame MPO file with a .jpg suffix. The test fixture uses
its primary frame, resized to 1024 pixels and saved as a still JPEG without EXIF.
This single regression example is not an evaluation dataset or recall estimate.
